# tennis-winprob
Data
4,082 men’s matches and 921,787 points
The splits are 3,366 matches for train, 231 for validation, and 485 for test.
1,415 Wimbledon, 1,361 US Open, 657 French Open, and 649 Australian Open matches. Clay is only about 16% of the data and absent from validation and test.
The French Open files have the most invalid rows, such as 13 in 2014, probably point-level gaps
